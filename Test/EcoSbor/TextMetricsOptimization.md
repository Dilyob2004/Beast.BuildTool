# Насыщенные UI-экраны: повторное измерение текста

21 сентября 2026. Изменение только в SDK: ограниченный thread-local кеш
`MeasureText` с точным ключом (строка, размер, FontFace). 512 записей максимум,
строки до 512 bytes; четыре кандидата на поиск/замещение. Встроенные шрифты
неизменяемы. Ни кеширования картинки всего экрана, ни потери чёткости не добавлено.

## Проверки Windows

Один и тот же тест 100 подписей × 120 кадров, Debug MSVC:

| Измерение | До | После |
| --- | ---: | ---: |
| 12 000 вызовов MeasureText | 142.892 ms | 1.996 ms (повтор: 2.060 ms) |
| Контрольная сумма ширин | 2876798.547 | 2876798.547 |

Это время повторных измерений, не всего UI/GPU. Проверены точные ключи размера
и шрифта, вытеснение, длинные строки, неверные аргументы, UTF-8 replacement,
regular/bold/icons и независимые потоки.

В WarmupBench EcoSbor после прогрева: CPU BuildFrame median 0.413 ms / p95
4.303 ms; предыдущий прогон до изменения — 1.178 / 7.747 ms. Отдельные прогоны
на Windows Debug, не обещание такого же коэффициента ускорения на Android.
Полный Run-Tests.ps1, /W4 /WX, реальные OpenGL/Vulkan окна, resize/recreation,
скролл и точный покой прошли. Windows Debug/Release и Android Release собраны.

## Телефон SM-A736B

Начальная трасса `Intermediate/Verification/beast-dense-before.pftrace`:
82 Submit, UI.Frame max 14.196 ms, UI.Paint mean 2.344 / max 9.123 ms;
FrameFence max 0.040 ms. В худшем Build 9.206 ms только 3.313 ms Running,
остальное Runnable: часть задержек связана с планированием CPU, не GPU-fence.

Попытка `beast-metrics-before.pftrace` не содержит Beast scopes и исключена
из сравнения. Причина отсутствия scopes не установлена.

Новая Release-копия `Binaries/Android/Release/LocalTest/EcoSbor-text-metrics.apk`
подписана существующим локальным Debug ключом, установлена через install -r
без очистки данных и запущена. Production/unsigned APK и отдельные символы
сохранены на стандартном пути.

Трасса после установки `beast-metrics-after.pftrace` содержит три жеста,
258 Submit, UI.Paint mean 1.734 / max 6.925 ms. Прямой A/B-коэффициент по этим
трассам некорректен: начальная содержит один release, новая — три и холодное
появление новых подписей. Оставшиеся выбросы UI.Frame до 18.350 ms включают
Text.Resolve до 5.278 ms внутри кадра и Prepare до 9.708 ms (новые текстуры).
Кеш метрик не устраняет холодную растеризацию/загрузку глифов; следующий
кандидат — подготовка текста, который вот-вот появится при прокрутке, с
ограничением работы и памяти. Отсутствие всех микролагов не заявляется.
