# Замеры рендеринга: пул слоёв и RepaintBoundary — 2026-09-14

## Следующий этап: RepaintBoundary

В SDK добавлен opt-in `Cached(child)` / `RepaintBoundary`. EcoSbor использует его
для баннера, совета дня и карточек гида. Инвалидация учитывает изменения ветки,
layout/DPI/theme, input/animation и clipping; целочисленный физический перенос
полностью видимой карточки переиспользует GPU-снимок. Частично скрытые карточки
рисуются напрямую — попытка пересоздавать их cropped targets каждый кадр была
отклонена по результатам замера: она давала 60 лишних allocations за 60 кадров.

Повторный замер после устранения этого случая, та же методика (Debug,
460×650, DPI 1,25, 15 warm-up + 60 frames, vsync/validation off, без других GPU-тестов):

| RHI | Raster cache | CPU Build median / p95, мс | CPU Submit median / p95, мс | GPU median / p95, мс |
|---|---|---|---|---|
| OpenGL | off | 1,483 / 2,451 | 0,392 / 0,625 | 0,748 / 1,157 |
| OpenGL | on | 1,337 / 2,455 | 0,392 / 1,848 | 0,703 / 1,037 |
| Vulkan | off | 1,545 / 2,583 | 0,536 / 0,805 | 0,708 / 1,093 |
| Vulkan | on | 1,528 / 2,469 | 0,532 / 1,038 | 0,666 / 0,951 |

В обеих cache-on сериях: **60 hits, 0 misses, 0 новых targets, 0 повторных
растеризаций кешируемого слоя** после прогрева, cachedBytes=376732. Частично
скрытый баннер рисуется напрямую, полностью видимый совет переиспользуется.
CPU Build OpenGL median уменьшился примерно на 10%, Vulkan — только на 1%.
Заметного общего ускорения/p95 по этому короткому замеру не утверждаем:
например, p95 Submit OpenGL стал хуже. Подтверждён именно пропуск paint и GPU
rasterization неизменной ветки, а не гарантированное повышение FPS всего экрана.

Лимит Context по умолчанию — 32 MiB и 64 записи. GetRepaintCacheStats позволяет
отличать полезные hits от misses/bypasses; установка бюджета 0 даёт контрольный
режим. Benchmark теперь сам выполняет cache off/on для каждого backend.
Пул GPU-памяти при этих замерах включён в обоих режимах.

Проверки: UIRepaintTests (CPU invalidation/input/tick/resize/theme, scroll,
budget/ownership, nested-layer fallback, Canvas transform и ошибка painter),
OpenGL pixel comparison при 9 DPI (75–400%), Vulkan validation и пересоздание
RHI. В первом pixel-прогоне максимальная разница с прямым рисованием — 2/255;
это допускаемая погрешность промежуточного RGBA8, не downscale текстур.
Сборка Android проверяется отдельно; pixel/runtime-тесты выше относятся к Windows.

Ниже сохранены измерения предыдущего этапа — только пула памяти, **до добавления
RepaintBoundary**. Их времена не являются прямым сравнением с текущей таблицей.

## Что изменено

SDK переиспользует свободные RGBA8 targets одного размера: OpenGL texture/FBO;
Vulkan image/memory/view/sampler/descriptors/FBO. Сначала дожидается существующего
frame fence и проверяет освобождение CPU-снимка. Затем новый слой получает
ресурс, очищает его и рисует новое содержимое. Живые снимки не перезаписываются.
Это **пул памяти**, не кеширование рисования и не RepaintBoundary.

По умолчанию свободный пул ограничен 32 MiB и 16 targets. Бюджет можно уменьшить
через RHIOptions.layerPoolBytes; 0 отключает пул для контрольного замера.
GPU timer и CPU Submit timer включаются отдельно через profiling=true.
Код EcoScene/Launch для работы пула не менялся.

## Методика и результат

Windows, Debug, Vulkan GPU AMD Radeon(TM) Graphics; OpenGL 4.6,
драйвер сообщает `25.10.36.08.260506`. Окно настроено на 460×650.
Vsync и validation выключены для замеров, 15 прогревочных + 60 измеряемых кадров.
Последний запуск выполнен без параллельных GPU-тестов Beast.
Для Vulkan порядок on/off обратный относительно OpenGL; это не устраняет
влияния частот/температуры/фоновой нагрузки, поэтому время не является test threshold.

Синтетическая сцена: восемь карточек, каждая с SaveLayer и ClipRRect — 16 слоёв.
Все они перезаписываются каждый кадр, а внутренний элемент меняет ширину.

| RHI | Пул | CPU Submit, median / p95 мс | GPU, median / p95 мс | Новые targets | Повторные использования |
|---|---|---|---|---:|---:|
| OpenGL | off | 0,531 / 0,858 | 1,248 / 1,450 | 960 | 0 |
| OpenGL | on | 0,388 / 0,605 | 1,048 / 1,182 | 0 | 960 |
| Vulkan | off | 10,733 / 12,970 | 0,819 / 0,893 | 960 | 0 |
| Vulkan | on | 0,511 / 0,954 | 1,106 / 1,229 | 0 | 960 |

Устойчивый проверяемый результат — **960 новых выделений заменены 960 reuse**
после прогрева на обоих RHI. В данном запуске существенно уменьшились затраты
CPU Submit Vulkan. GPU-время Vulkan не улучшилось: пул не сокращает объём
рисования, а разные режимы подачи команд/частоты GPU влияют на измерение.
Не трактовать результат как ускорение всего приложения в 20 раз.

Отдельно измерен настоящий скролл главной страницы EcoSbor, без копирования
списка команд из Context:

| RHI | Построение UI, median / p95 мс | CPU Submit, median / p95 мс | GPU, median / p95 мс |
|---|---|---|---|
| OpenGL | 1,317 / 1,728 | 0,300 / 0,597 | 1,131 / 1,204 |
| Vulkan | 1,184 / 1,564 | 0,464 / 0,802 | 0,880 / 1,054 |

В этом сценарии offscreen layers отсутствуют: allocations=0, reuses=0.
Ускорение скролла за счёт пула не заявляется. Старый CPU-only ScrollBench при
1080×1800, DPI 2,625 дал median 0,491 / p95 1,942 мс и 6 новых текстур за 31 переход;
до изменений было 0,487 / 1,947 мс, те же 6 текстур. Это другой viewport/сценарий,
напрямую сравнивать его время с таблицей GPU-бенчмарка нельзя.

CPU Submit включает ожидания и presentation. GPU timestamps измеряют интервал
рисования без presentation (на GL также без финального blit); возможны stalls.
59 GPU samples на 60 кадров обусловлены асинхронным получением результата.
Значения разных столбцов не складываются в latency: CPU и GPU выполняются
конвейерно. Отсутствие GPU-меток означает unavailable, а не 0 мс.

## Как повторить

Из корня репозитория:

```powershell
.\BuildTool\bin\Beast.BuildTool.exe build Test/EcoSbor --platform Windows --config Debug
.\Test\EcoSbor\Tests\Run-RenderBench.ps1
```

Не запускать одновременно другие GPU-тесты. Журнал последнего запуска:
`Intermediate/Verification/RenderBench.log`. Скрипт проверяет число allocations/
reuses/renders и бюджет памяти; точное время не используется как условие успеха.

Корректность отдельно проверяет `BeastSDK/Tests/Run-UIShapeTests.ps1`:
пул с лимитами/вытеснением; optional GL timer; 9 DPI; перезапись цвета;
сохранённый старый снимок; повторная выдача targets; native-resolution текст;
пересоздание RHI. Для Vulkan включён validation, в том числе с profiling.
OpenGL pixels сравниваются с независимым эталоном, ошибка не более 1/255
в проверенной сцене. Vulkan pixel readback в этом наборе не реализован.

Windows и Android собираются. Android GPU/runtime-замеры пока не выполнены:
APK-сборка проверяет совместимость исходников, но не поведение драйвера устройства.
