# Подготовка ближайшего текста — 26 сентября 2026

## Изменение

Раньше idle-прогрев открывался только для уже видимых строк. Теперь Canvas
обнаруживает короткие подписи в запасе за viewport Subpixel-scroll: половина
размера viewport в каждую сторону вдоль оси, максимум 256 логических единиц.
Дальний текст остаётся холодным. Резерв отделён от content/effect clips:
невидимый текст не рисуется, реальные scissors, тени и качество покрытия прежние.
Дополнительный обход дерева не нужен. Максимум 64 невидимых подписи за paint;
очередь ограничена 128 заданиями / 256 ключами, как прежде.

WarmStep проверяет мягкий deadline 750 μs между глифами. Незаконченная фаза
продолжается позже; уже подготовленные глифы сохраняются. Новые/COW страницы
ограничены 512 KiB за шаг; общий бюджет атласа остаётся 16 MiB. Layout, один
вызов rasterizer, sealing и задержки планировщика могут превысить временную цель.
Это кооперативный бюджет, не real-time гарантия. Обычная видимая растеризация
сохраняет прежний лимит 16 MiB новых данных за кадр.

Context не прогревает текст во время drag/animation и один раз обнаруживает
новую окрестность после остановки движения. Подготовленные страницы загружаются
обычным RHI-путём через прозрачные вырожденные треугольники без видимого покрытия.

## Локальный CPU-замер EcoSbor

`WarmupBench.cpp`, Windows Release MSVC `/O2 /MD`, scale 2.625,
1080×1800, 32 кадра с настоящей маршрутизацией touch. Сравниваются новая версия
без прогрева и та же версия после idle-прогрева. Это **не** прямой замер старого
коммита против нового и **не** GPU/presentation latency или данные телефона.

## Что остаётся

Телефон не подключён (`adb devices -l` пуст), установка и новый Perfetto-замер
на физическом Android не выполнены. Нельзя считать все микролаги устранёнными.
Быстрый первый жест может опередить прогрев, длинный fling выйти за резерв.
256 ключей — конечный лимит, не виртуализация произвольного списка. Подготовка
layout/run и команд, количество draw calls и работа на насыщенных экранах
остаются отдельными следующими измеряемыми задачами. Hot reload остаётся в ROADMAP.
